三、技术路线聚类

① Fault Seal / Fault Transmissivity

核心问题是断层究竟是“封堵器”还是“输导通道”。典型技术包括 lithologic juxtaposition、fault-rock permeability、shale smear、压力差、应力状态以及地震响应等。

WO2010082023WO2024100220WO2025106067

② Migration Pathway

重点是从 source → carrier → fault/fracture → reservoir 的路径识别，包括基于地质属性迭代、地震属性、源/目的储层反向追踪等。

WO2014117114WO2021048597

③ Hydrocarbon Migration & Accumulation

从单一断层分析扩展到盆地尺度的生成、排烃、迁移和圈闭充注过程模拟，重点关注迁移质量、时间和空间连续性。

WO2019147625

④ Seismic Fault-Seal Prediction

利用 pre-stack seismic、AVA、fault-plane reflection、波形拟合等信息，把不可直接观测的 fault seal 转化为可计算/可预测的地震属性问题。

WO2018215865WO2018215866

⑤ Geomechanics

将断层、应力、孔隙压力与流体运移统一到地质力学模型中，重点关注断层再活化、流体流动与迁移通道。

WO2021048597WO2025090857

⑥ Seep / Microseepage

通过海底油气渗漏、气泡链、微生物垫、油膜等表征地表/海底异常，再反演地下油气来源和可能的 fault/fracture migration pathway。

WO2013071185WO2018005517

四、与“fault & hydrocarbon migration”直接相关的关键发现

1. 断层不是单纯的封堵体。公开专利通常把 fault 同时描述为 hydrocarbon migration pathway、fluid-flow barrier 或两者在不同条件下的转换体；因此检索时不能只搜索 “fault seal”，还应覆盖 transmissivity、fluid flow、migration pathway、juxtaposition、shale smear 和 geomechanics。
2. 近年来技术重点明显向“可计算预测”发展。早期代表性专利偏向 fault analysis system；随后出现基于 seismic/AVA 的 fault seal prediction、迁移路径数值迭代、盆地油气迁移模拟；2024–2025 年又出现 Shell 的 fault seal behaviour / fluid flow field，以及 Landmark 的 probabilistic shale smear。
3. 如果你的目标是“断层油气输导能力评价”，建议重点关注：WO2010082023 → WO2014117114 → WO2018215865/5866 → WO2021048597 → WO2024100220 → WO2025090857 → WO2025106067。这一链条基本覆盖“断层表征 → 封闭性 → 迁移路径 → 地质力学 → 流场 → 页岩涂抹概率”的技术演进。
